# Tsuji (辻) — Showcase & Technical Reference

Official showcase website and technical reference for **Tsuji**, a real-time 3D nodal studio engine built on Three.js and Rapier 3D (WASM).

- **Engine Repository:** [https://github.com/Nikos-Unilasalle/tsuji](https://github.com/Nikos-Unilasalle/tsuji)
- **Web Application:** [https://tsuji.xyz](https://tsuji.xyz)
- **Live Showcase:** [https://nikos-unilasalle.github.io/tsuji-site](https://nikos-unilasalle.github.io/tsuji-site)

## Features

- Three.js WebGL interactive background and telemetry modes
- Real-time Direct Linear Transformation (DLT) video-mapping solver simulator
- Exhaustive catalog of all 305 operational nodes with category filtering and search
- Studio keyboard shortcuts reference
- Multi-language architecture (French, English, Japanese, Chinese)
- Lightweight, zero-dependency static site (GitHub Pages ready)
